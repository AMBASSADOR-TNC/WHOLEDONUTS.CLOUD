# CRUMB SAVER (CS-1)

**Specification only, not a deployed service.** The flows and outputs below are
design goals, not running behavior. See the [Bathroom Door safety boundary](crumb-code.md#bathroom-door-safety-boundary).

The Crumb Saver collects every idea, note, draft, spark, and fragment
created inside or around the Whole Donuts ecosystem.

## Purpose
To ensure nothing is lost, nothing is wasted, and every crumb has a home.

## What Counts as a Crumb
- Notes
- Drafts
- Phrases
- Sketches
- Movement seeds
- Helper ideas
- Domain fragments
- Micro-product concepts
- Early Whole Donuts Cloud identity pieces
- Unfinished thoughts
- Forgotten files

## Crumb Flow
1. Capture crumb
2. Tag crumb (identity, community, routing, domain, donor, helper)
3. Store crumb
4. Route crumb to correct subsystem
5. Convert crumb into value (PDF, helper action, lane, domain, OS component)

## Crumb Categories
- Identity crumbs
- Sunshine crumbs
- ACCESS crumbs
- Domain crumbs
- Donor crumbs
- Helper crumbs
- OS crumbs

## Crumb Output
- Micro-products
- Helper actions
- Domain pages
- OS modules
- Movement language
- Ecosystem expansions

## Status
Crumb Saver is not operational. No personal submissions, user-data ingestion,
automated storage, processing, or rewards service is enabled by this specification.
