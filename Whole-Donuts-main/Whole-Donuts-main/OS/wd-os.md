# WHOLE DONUTS OPERATING SYSTEM (WD‑OS)

The WD‑OS is the unified operating system that powers the Whole Donuts ecosystem.

## Public entry source

`AMBASSADOR-TNC/WHOLEDONUTS.CLOUD` is the sole maintained public source for the
[universal four-figure +U entry](../../../entry/index.html). WHNutz is retired
from this tree; its dedicated source bundle has been removed. Unrelated bundled
copies and Git history are preserved.

`wenevergonnaclose.com` is the intended public domain, pending DNS, Pages mapping,
and certificate verification. The existing Cloud `CNAME` and Pages configuration
are unchanged. This does not claim that external domains or services are operational.
Entry selections and varied +U messages run locally; external routing remains
blocked, and no backend, payment, rewards, or Crumb service is activated.
See [operational status and the Bathroom Door boundary](../../../entry/status.html).

The entry markup, styles, engine, and baseline tests originate from
`AMBASSADOR-TNC/WENEVERGONNACLOSE` commit
`b2bf526d6580f4f4b00f862a69b370238968fc02`, integrated under `entry/`.

## Subsystems

### 1. Identity System (Whole Donuts Cloud)
Defines who we are when we help.

### 2. Community System (Sunshine)
Defines how we lift people.

### 3. Routing System (ACCESS)
Defines how needs move through the ecosystem.

### 4. Domain System (28-domain map)
Defines where people enter the ecosystem.

## Purpose
To unify all lanes, domains, and helper actions into one continuous, never-closing flow.
