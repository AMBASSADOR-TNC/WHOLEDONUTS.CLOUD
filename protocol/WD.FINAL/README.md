# WD.FINAL — Completion Folder

This folder holds all finished protocol tasks.

## File Naming Format
AAA-****-[I|R|M]-taskname.ext

AAA = 3-character identity tag  
**** = priority stars  
I = Improve  
R = Remove  
M = Merge  

## Workflow
1. All new files go into /pending/
2. Only after permission, files move to /approved/
3. Approved files may then be committed to GitHub
